# FlightIQ demonstration dataset

`flights_demo.csv` contains 15,000 deterministic synthetic records generated by
`backend/python/generate_dataset.py` with seed `42`.

It models plausible relationships between weather, congestion periods, season,
airline, airport, distance, and delay. It is intended for reproducible portfolio
demonstrations and automated model verification—not operational travel advice.

Regenerate the dataset and model from the project root:

```powershell
.\.venv\Scripts\python.exe backend\python\run_pipeline.py
```

The pipeline exports the trained Joblib artifact and measured test metrics into
`backend/python/artifacts/`.
